## Статус реализации (DPT.Agent)

Сделано:

- [x] `.NET Framework 4.0` / C# 4, только BCL, сборка стоковым `csc.exe` (`build.cmd`), без NuGet/MSBuild.
- [x] Логирование через `Trace` без `app.config`: один файловый листенер (полный verbose),
      один консольный (только важные категории), `DefaultTraceListener` снят — дублей нет,
      ротация по дню и размеру, ring-буфер для веб-морды. См. `docs/LOGGING.md`.
- [x] Динамическая отказоустойчивость: `Guard` / `Retry` (exponential backoff + джиттер) /
      `CircuitBreaker` / `Supervisor` с перезапуском листенера, fallback-порты, лимиты
      соединений, атомарная запись файлов. См. `docs/RESILIENCE.md`.
- [x] Веб-морда `public/`: хром 2008 (VK/FB), современные тени/переходы, темы
      `light`/`dark`/`oled`, WebAudio-звуки без файлов, RU/EN с автодетектом.
- [x] Проекты в `workspace/` (`project.json`, рабочее дерево `files/`, `export/`),
      журнал операций как история совместной работы.
- [x] Сессии с кодами (`ABCD-2345`), оффлайн и онлайн, присутствие участников,
      синхронизация long-poll-ом. См. `docs/SESSIONS.md`.
- [x] Очередь фоновых заданий с прогрессом и кооперативной отменой.
- [x] Headless CLI на все операции + `serve` c консольным REPL.
- [x] Форматы: CSO/ZSO ↔ ISO (проверено на реальных образах), ISO 9660 разбор и
      сборка (round-trip побайтово), IMG (Stories/DIR/VER2/скан чанков), GAME.DTZ ↔ GAME.DAT,
      таблица стриминга LCS → `.DIR` (536 моделей + 585 текстур, сверено с IMG),
      CHK/XTX текстуры (палитра, PSP swizzle, mip, PNG — проверено визуально),
      GXT в текст, VAG ↔ WAV, определение формата по содержимому.
- [x] `data/modelnames.lcs.txt` / `.vcs.txt` — 3658/4033 имени моделей,
      генерируются `tools/build_modelnames.py` из дампов g3DTZ.
- [x] Документация: `docs/FORMATS.md` (все измеренные смещения + честный список пробелов),
      `ARCHITECTURE.md`, `SESSIONS.md`, `WEB.md`, `LOGGING.md`, `RESILIENCE.md`, `ROADMAP.md`.
- [x] `.git` инициализирован, `refs/` в `.gitignore`.
- [x] Тесты одной командой: `tools/ci-test.ps1` — сборка + 14 проверок форматов +
      25 проверок HTTP API, всё зелёное.
- [x] `refs/` подготовлен: склонированы `cso-to-iso` и `g3DTZ`, оба CSO сконвертированы
      в ISO и распакованы в `refs/GAMES/extracted/{LCS,VCS}` (в git не попадают).
- [x] **Запись текстур**: `chk-replace` и кнопка «↥» в инспекторе — PNG возвращается в
      CHK с переиспользованием палитры, swizzle и пересборкой mip-цепочки в цветовом
      пространстве. Round-trip «экспорт → импорт» даёт побайтово тот же PNG.
- [x] **Замена и сборка IMG**: `img-replace` пишет файл в существующий диапазон секторов
      (размер архива и стриминг не ломаются, рост отклоняется с объяснением),
      `img-pack` собирает IMG+DIR из папки. Замена тем же файлом даёт побайтово тот же IMG.
- [x] **Текст (GXT)**: формат разобран заново — ключи это имена, строки UTF-16LE,
      блоки выровнены по 4 байта; `gxt-dump` даёт правимый файл, `gxt-import` собирает
      обратно и для неизменённого текста отдаёт **байт в байт** исходник.
- [x] **Пересборка с синхронизацией стриминга** (`img-repack`): влезающие записи пишутся
      на месте, выросшие уезжают в конец образа, и в `GAME.DAT` правится только их слот.
      Попутно измерено, что розничный IMG **не** упакован подряд (175 дыр и 3.5 МБ хвоста
      вне таблицы) — поэтому «собрать всё с нуля» потеряло бы 12 МБ данных игры.

Осознанные решения и границы:

1. **g3DTZ переписан, а не слинкован**: C++-логика (relocatable chunk, `CStreaming`,
   `CPool`, TexListDef) реализована в `Formats/Rsl.cs` + `Formats/Dtz.cs`. Читать чанк
   можно без релокации: в файле указатели уже лежат как смещения.
2. **VCS таблица стриминга** пока не разобрана (смещения структуры сходятся, содержимое
   нет) — VCS IMG разбирается сканированием чанков, `dtz-dir` для VCS честно отказывает
   с пояснением. Это первая задача в `docs/ROADMAP.md`.
3. **Запись текстур** сделана для pal4/pal8. Не сделана для 16/32bpp и DXT
   (нужен упаковщик DXT; декодер уже есть) и mip-цепочка для pal4.
4. **PMF/AT3/SCM/Lua** — только идентификация и метаданные (декодеры вне BCL).
5. **Аутентификации нет**: сервер слушает `127.0.0.1`, для LAN — `bind=0.0.0.0` и
   reverse proxy с авторизацией.

Проверено: `tools/ci-test.ps1` — build ok, форматы 20/20, веб 25/25.
Визуально: загрузочный экран LCS и лицо Тони из `player.chk` декодируются корректно,
ISO из распакованного дампа собирается и распаковывается побайтово тем же.
